# Manish Y M — Manga Portfolio

One Piece–inspired **grayscale manga portfolio** built with React + Vite + TypeScript.

## Sections (matches design mockup)

1. **01 — The Wanted Poster** — Hero with your bounty poster + intro
2. **02 — Prologue** — Journal entry, skills inventory, education
3. **03 — Specialists On Board** — Tech stack as crew roles
4. **04 — The Repositories** — Dramatic manga spread divider
5. **05 — Adventures** — Flagship project cards with charts
6. **06 — Battles & Shipwreck Lessons** — Post-mortem cards
7. **07 — Final Spread** — Contact form + shipping info
8. **Footer** — "TO BE CONTINUED..."

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`

## Customize

- Content: `src/data/profile.ts`
- Hero poster: `public/wanted-poster.jpg`
- Styles: `src/index.css`
